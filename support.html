使用中遇到问题、发现卡片内容有错，或者想要新增考试科目，请发邮件到：hhheartkz@outlook.com，一般 3 个工作日内回复。

常见问题

换手机后购买记录不见了？ 在「设置 → 解锁卡片 / 恢复购买」里点「恢复购买」，用同一个 Apple ID 即可找回。

学习记录怎么转到新手机？ 登录同一个 Apple ID 的 iCloud 会自动同步；也可以在「设置 → 备份文件」导出再导入。

卡片内容会更新吗？ 会。新的卡片和科目会自动下载，重新打开 App 后生效。

怎么提交自己整理的词？ 在「卡片」页点「添加自己的词」，打开「提交给开发者审核」即可。
